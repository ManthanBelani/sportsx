# SportX India — MVP Overview

## What is SportX India?

SportX India is a discovery and connection platform for India's sports ecosystem. It brings together **athletes and parents**, **coaches**, **academies**, **trial/tournament organizers**, and **sponsors/brands** in one place — so athletes can find opportunities (academies, coaches, trials, tournaments, scholarships, sponsorships) and the other side (coaches, academies, organizers, sponsors) can find and manage athletes.

At its core, the app has two jobs:
1. **Discovery** — let athletes/parents search and filter academies, coaches, trials, tournaments, scholarships, and sponsorships.
2. **Connection & Management** — let coaches, academies, organizers, and sponsors publish listings, manage enquiries/registrations, and find athletes.

An **Admin** team sits behind the scenes to keep the data clean, moderate listings, and manage master categories (sports, cities, age groups).

---

## Who Are the Users? (Roles)

| Role | What they mainly do on the app |
|---|---|
| **Athlete / Parent** | Discover academies, coaches, trials, tournaments, scholarships, sponsorships. Build a profile. Register/apply. |
| **Coach** | List their coaching services, respond to enquiries, and also browse the app like an athlete/parent. |
| **Academy** | List their academy, post trials, manage trial registrants, respond to enquiries. |
| **Organizer** | Post and manage trials and tournaments, handle registrations, publish results. |
| **Sponsor / Brand** | Post sponsorship opportunities, discover athletes, review applications, shortlist candidates. |
| **Admin** | Maintain data quality — add/edit/remove listings, moderate flagged content, manage expiry rules and master categories. |

## 1. Athlete / Parent

This is the primary consumer of the app — searching for opportunities and putting themselves out there.

### How they use the app
1. **Sign up** with phone or email, and complete onboarding (sport, age group, skill level, city).
2. **Build a profile** — basic info, sport/discipline, achievements, and a media gallery of photos/videos.
3. **Browse and search** academies, coaches, trials, tournaments, scholarships, and sponsorships — using a single universal search bar and consistent filters (sport, city, age, price, date).
4. **Take action** — enquire with a coach, register for a trial or tournament, apply/pitch to a sponsor.
5. **Stay updated** — get reminders as saved trial/tournament dates or scholarship deadlines approach.
6. **Flag problems** — report any listing that looks fake, outdated, or suspicious.

### Feature List

| Feature | Description |
|---|---|
| Sign Up / Login | Register via phone or email; onboarding captures sport(s), age group, skill level, city/location. |
| Digital Profile | Basic info, sport(s)/discipline, achievements, and a media gallery (photos/videos). |
| Academy Directory | Browse all academies — sport, location, contact, fees, facilities, coaches, age groups, timings. |
| Search & Filter Academies | Filter by sport, city, state, age group, price range. |
| Coach Directory | Browse individual coaches — sport, qualifications, experience, location, fees. |
| Search & Filter Coaches | Filter by sport, city, price. |
| Book/Enquire with Coaches | Contact a coach in-app to request a session or ask a question. |
| Trial Listings | Browse trials — name, sport, organizer, date, venue, eligibility, entry fee, contact, required documents. |
| Search & Filter Trials | Filter by sport, city, age category, date range. |
| Trial Registration | Register for a trial in-app (or via external link where applicable). |
| Tournament Calendar | Browse tournaments in calendar/list view — format, dates, venue, eligibility, prize pool, entry categories. |
| Tournament Registration | Register for a tournament in-app. |
| Scholarship Feed | Browse a curated, admin-maintained list of active scholarships/schemes — provider, sport, eligibility, amount, deadline. |
| Sponsorship Opportunities | Browse sponsorship listings — eligibility, sport, benefits offered. |
| Apply/Pitch to Sponsors | Submit profile + a pitch note to a sponsorship listing. |
| Universal Search | Single search bar across academies, coaches, trials, tournaments, scholarships, and sponsorships. |
| Global Filters | Consistent filters (sport, age, location, price, date) across the app. |
| Deadline & Date Reminders | Push notification as saved trial dates, tournament dates, or scholarship deadlines approach. |
| Report a Listing | Flag a listing as fake, stale, or suspicious. |

## 2. Coach

A coach is both a **service provider** (listed and discoverable) and a **regular user** (can browse the app freely).

### How they use the app
1. Create a **profile/listing** with certifications, experience, sport(s) coached, fees, and location.
2. Receive and respond to **enquiries** from athletes/parents in an inbox.
3. Otherwise use the app exactly like an athlete/parent — browsing academies and trials.

### Feature List

| Feature | Description |
|---|---|
| Own Profile Creation | Build and edit a listing: certifications, experience, sport(s) coached, fee structure, location. |
| Enquiry Inbox | View and respond to booking/enquiry requests from athletes/parents. |
| Browse Like Any User | Full access to browse/search academies and trials like any athlete/parent. |

---

## 3. Academy

An academy manages its own presence on the platform and runs trials directly.

### How they use the app
1. Create and maintain an **academy listing** — sports offered, facilities, location, fee range, photos.
2. **Post trials** under the academy's name — create, edit, publish, and close them as needed.
3. **Manage registrants** — see who has signed up for each trial.
4. Respond to **enquiries** from interested athletes/parents.

### Feature List

| Feature | Description |
|---|---|
| Own Listing Creation | Build and edit the academy's listing: sport(s) offered, facilities, location, fee range, photos. |
| Trial Posting | Create, edit, publish, and close trial listings under the academy's name. |
| Registrant Management | View the list of athletes registered for the academy's trials. |
| Enquiry Inbox | Respond to enquiries sent by athletes/parents. |

---

## 4. Organizer (Trial / Tournament)

Organizers run standalone trials and tournaments (not tied to a specific academy).

### How they use the app
1. **Create and manage trial listings** — publish or close them as needed.
2. **Create and manage tournament listings** — format, dates, venue, entry fees, prize pool.
3. **Track registrations** and manage available capacity/spots.
4. **Publish results** — post brackets or final standings once an event concludes.

### Feature List

| Feature | Description |
|---|---|
| Trial Listing Management | Create, edit, publish, and close trial listings. |
| Tournament Listing Management | Create, edit, and publish tournament listings — format, dates, venue, entry fees, prize pool. |
| Registration Management | View the list of registrants and manage event capacity/spots. |
| Results Publishing | Post brackets or final results once a tournament is complete. |

---

## 5. Sponsor / Brand

Sponsors use the app to find and evaluate athletes worth backing.

### How they use the app
1. **Post a sponsorship opportunity** — sport, eligibility criteria, and benefits offered.
2. **Discover athletes** by browsing and searching profiles that match their criteria.
3. **Review applications** — athletes' pitches land in an applications inbox.
4. **Shortlist** promising profiles for follow-up.

### Feature List

| Feature | Description |
|---|---|
| Sponsorship Listing | Post a sponsorship opportunity — sport, eligibility criteria, benefits offered. |
| Athlete Discovery | Browse and search athlete profiles matching sponsorship criteria. |
| Applications Inbox | Review pitches/applications athletes have submitted. |
| Shortlisting | Save/shortlist promising athlete profiles for follow-up. |

---

## 6. Admin (Internal / Platform Team)

Admins are not end-users of the marketplace — they're the platform team keeping everything clean and trustworthy.

### How they use the app
1. **Seed and correct data** directly — add, edit, or delete records across any category.
2. **Moderate content** — review listings flagged/reported by users and remove fake or stale entries.
3. **Configure expiry rules** — set up and monitor automatic expiry for trials once their date has passed.
4. **Manage master data** — sports types, cities, and age categories used across all filters and forms.

### Feature List

| Feature | Description |
|---|---|
| Content CRUD | Add, edit, or delete records directly across any category — used to seed and correct data. |
| Listing Moderation | Review flagged/reported listings and remove fake or stale entries. |
| Content Expiry Rules | Configure and monitor automatic expiry for trials once their date has passed. |
| Category Management | Manage master lists — sport types, cities, age categories. |

## How It All Connects

```
Athlete/Parent  ──── discovers & registers ────►  Academies, Coaches, Trials,
                                                     Tournaments, Scholarships
Athlete/Parent  ──── applies/pitches ──────────►  Sponsors

Coach           ──── lists services, replies ──►  Athlete/Parent enquiries
Academy         ──── posts trials, manages ────►  Registrants & enquiries
Organizer       ──── posts trials/tournaments ─►  Registrations & results
Sponsor         ──── posts opportunities ──────►  Athlete applications

Admin           ──── moderates & maintains ────►  All of the above
```

**Note:** The "Athlete additions needed to support Organizer & Sponsor" items from the original spec (Tournament Calendar, Tournament Registration, Sponsorship Opportunities, Apply/Pitch to Sponsors) have been folded directly into the **Athlete / Parent** feature list above, since that's the role that actually uses them.

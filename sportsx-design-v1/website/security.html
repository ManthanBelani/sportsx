Security

How we protect your data, your account, and your trust in SportX.

TLS/SSL Encrypted
AES-256 Storage
ISO 27001 Infra
Back to About

At SportX, security isn't an afterthought — it's foundational. We understand that you're trusting us with personal information, and we take that responsibility seriously.

Data Encryption

All data encrypted in transit (TLS/SSL) and at rest (AES-256).

Access Controls

Strict role-based access controls for user data.

Regular Audits

Quarterly security audits and penetration testing.

Infrastructure Security

Our Platform runs on ISO 27001-certified cloud infrastructure with:

  • Geographic redundancy — Data replicated across multiple availability zones
  • DDoS protection — Cloud-native and application-layer DDoS mitigation
  • Firewall & WAF — Web Application Firewall protecting against OWASP Top 10 threats
  • Backup & recovery — Daily automated backups with point-in-time recovery
  • 24/7 monitoring — Real-time alerting for anomalous activity

Account Security

  • Password Requirements — Passwords must be at least 8 characters. We never store passwords in plain text — only salted hashes.
  • 2-Factor Authentication — 2FA via OTP (SMS/Email) or authenticator apps is available for all users.
  • Suspicious Login Alerts — We monitor for unusual login patterns and notify you immediately.
  • Session Management — Active sessions are visible in account settings. You can revoke any session.

Payment Security

All payments on SportX are processed through PCI-DSS compliant providers (Razorpay, UPI). SportX does not store your full card number, CVV, or bank account details. All payment data is tokenized and encrypted by the provider.

Verification & Anti-Fraud

We employ multiple layers to prevent fraud and fake accounts:

  • Phone number and email verification during signup
  • Document verification for coaches, academies, and sponsors
  • ML-based anomaly detection for suspicious behaviour
  • Manual review of flagged listings and accounts
  • User reporting tools for inappropriate content or behaviour

Bug Bounty Program

We run a responsible disclosure program for security researchers. If you discover a security vulnerability, report it to security@sportx.in. We aim to acknowledge within 24 hours and resolve critical issues within 7 days.

Report a Security Issue

If you've identified a security vulnerability or have concerns about your account:

  • Email: security@sportx.in (for vulnerabilities)
  • Email: support@sportx.in (for account issues)
